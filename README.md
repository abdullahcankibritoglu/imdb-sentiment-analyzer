# 🎬 IMDB Sentiment Analyzer

A machine learning web application that classifies IMDB movie reviews as **positive** or **negative** — with confidence scores and word-level explainability.

---

## 📁 Project Structure

```
imdb_sentiment_analyzer/
├── train.py            ← Trains the model and saves pipeline.pkl
├── app2.py             ← Streamlit web interface
├── IMDB Dataset.csv    ← 50K labeled IMDB reviews
└── pipeline.pkl        ← Serialized model (generated by train.py)
```

---

## 🏗️ Architecture

```
Raw Review
    │
    ▼
┌─────────────────────────────────────────────────────┐
│  TextCleaner (custom sklearn TransformerMixin)      │
│  • Fix encoding anomalies          (ftfy)           │
│  • Strip HTML tags                 (BeautifulSoup)  │
│  • Remove emojis                   (regex)          │
│  • Normalize punctuation           (regex)          │
│  • Remove URLs                     (regex)          │
│  • Lowercase                                        │
│  • Remove stopwords — keep negations                │
│    (not, no, never, neither, nor, hardly, barely)   │
└─────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────┐
│  TF-IDF Vectorizer                                  │
│  • max_features = 1000                              │
│  • ngram_range  = (1, 2)   ← unigrams + bigrams     │
│  • sublinear_tf = True     ← log normalization      │
└─────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────┐
│  Logistic Regression                                │
│  • max_iter = 1000                                  │
│  • Outputs: class label + predict_proba()           │
└─────────────────────────────────────────────────────┘
    │
    ▼
Positive 😊 / Negative 😔 + Confidence % + Key Words
```

## ✨ Features

| Feature | Description |
|---|---|
| 🎯 Prediction | Binary sentiment classification |
| 📊 Confidence Score | Per-class probability via `predict_proba()` |
| 🧠 Explainability | TF-IDF weight × LR coefficient = word contribution |
| 🟢🔴 Text Highlighting | Positive/negative words highlighted inline |
| 🧹 Cleaned Text View | Inspect preprocessed input (optional) |
| ⚙️ Sidebar Controls | Toggle keyword view and cleaned text |

---

## 🧠 Explainability Method

Word-level contribution is computed as:

```
contribution(word) = tfidf_score(word) × lr_coef(word)

contribution > 0  →  pushes toward Positive  🟢
contribution < 0  →  pushes toward Negative  🔴
```

This is a lightweight alternative to SHAP/LIME — interpretable without additional dependencies.
